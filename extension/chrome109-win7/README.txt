Rezkery Randomizer 1.1.0
========================

Что нового
-----------
1. Настройки открываются кнопкой ⚙ в верхней части.
2. Можно указать любой совместимый домен/зеркало, например https://rezka.fi.
3. Домен сохраняется в storage и используется для новых запросов.
4. Экспортированный HTML получает выбранный домен в ссылках карточек и в JSON внутри HTML.
5. Рандомизация выполняется через background: Chrome использует Manifest V3 service worker, Firefox — background script.
6. Временные вкладки для разбора страниц создаются неактивными; выбранные карточки открываются после записи в базу.
7. Категории используют реальные ветки сайта:
   all: / и /page/N/
   film: /?filter=last&genre=1 и /page/N/?filter=last&genre=1
   series: genre=2
   cartoon: genre=3
   anime: genre=82
8. Для года к пути /year/YYYY/ добавляется соответствующий genre при выборе категории.
9. Количество страниц года определяется по пагинации и переходам Next.
10. Последние страницы могут содержать меньше 36 карточек — берётся фактическое число.

Разрешения
----------
Для поддержки произвольных зеркал используется scripting + host_permissions <all_urls>.
Это необходимо для программной загрузки parser content.js на пользовательский домен.

Установка Chrome
----------------
1. Распакуйте ZIP.
2. chrome://extensions/
3. Включите «Режим разработчика».
4. «Загрузить распакованное расширение».

Chrome 109 / Windows 7
----------------------
Используйте архив chrome109-win7. Manifest содержит MV3 service_worker и не использует новые API после Chrome 109.

Firefox
-------
about:debugging -> Этот Firefox -> Загрузить временное дополнение -> manifest.json.
Для постоянной установки обычному Firefox требуется подписанный пакет Mozilla.

Примечание по домену
--------------------
Зеркало должно иметь совместимую структуру страниц и карточек. Можно вводить rezka.fi или https://rezka.fi.
Если зеркало использует другой HTML-шаблон, его карточки могут потребовать отдельного адаптера parser.
