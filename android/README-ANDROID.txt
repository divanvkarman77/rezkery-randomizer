Rezkery Randomizer — Android 1.0
================================

Это небольшой нативный Android-проект. Он позволяет:
- сохранить домен/зеркало;
- выбрать Все / Фильмы / Сериалы / Мультфильмы / Аниме;
- при желании указать год;
- открыть случайную страницу каталога;
- выбрать случайную ещё не использованную карточку;
- открыть выбранный материал во внешнем браузере;
- хранить список уже открытых URL локально.

Сборка:
1. Откройте папку android-app в Android Studio.
2. Дождитесь загрузки Gradle.
3. Используйте Android SDK с compileSdk 35.
4. Build -> Build APK(s).

В этой среде готовый APK не собран: здесь отсутствует Android SDK/Gradle toolchain. Исходный проект готов для Android Studio.
