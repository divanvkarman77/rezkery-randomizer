# RezKery Randomizer

Проект рандомайзера каталога rezkery.com: браузерное расширение для Chrome/Chromium и Firefox, а также исходный Gradle-проект Android-приложения.

## Состояние переноса

В репозитории сейчас размещены базовая документация, лицензия, журнал изменений и заготовки GitHub Actions. **Исходные файлы расширений и Android пока не перенесены в дерево репозитория**, поэтому workflows ещё не проверены запуском и не следует считать проект полностью опубликованным.

Полный подготовленный архив исходников доступен отдельно: [скачать ZIP проекта из чата](sandbox:/mnt/data/rezkery-randomizer-repository.zip). Чтобы включить исходники в этот репозиторий, распакуйте архив и загрузите содержимое каталога `rezkery-randomizer-repo/` в корень репозитория, сохранив структуру каталогов.

После загрузки исходников нужно проверить GitHub Actions и протестировать расширения в целевых браузерах. Используйте проект в соответствии с правилами сайта и применимым законодательством.
