# RezKery Randomizer

Расширение для случайного выбора фильмов, сериалов, мультфильмов и аниме с rezkery.com, с локальной историей просмотренных карточек. В репозитории также планируются сборки для Chrome/Chromium и Firefox, исходники Android-приложения, документация и GitHub Actions.

## Локальная сборка

См. `docs/build-and-test.md` и `docs/architecture.md`.

## Платформы

- Chrome 109 / Windows 7
- Современный Chrome / Chromium
- Firefox 115 ESR
- Современный Firefox
- Android (исходный Gradle-проект)

## Важно

APK не включён: его нужно собрать через Android SDK/Gradle. Используйте расширение в соответствии с правилами сайта и применимым законодательством.
