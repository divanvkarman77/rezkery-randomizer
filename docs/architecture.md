# Архитектура

Проект состоит из браузерного расширения и исходников простого Android-приложения.

## Расширение

- `manifest.json` задаёт разрешения, popup и фоновый сценарий.
- `popup.html`, `popup.css`, `popup.js` реализуют интерфейс случайного выбора, фильтров и локальной базы.
- `content.js` извлекает карточки каталога RezKery со страниц сайта.
- `background.js` выполняет фоновые задачи и открывает выбранный материал в новой вкладке.
- Локальное хранилище браузера используется для истории и исключения повторов.

## Варианты сборок

- `extension/chrome109-win7/` — совместимость с Chrome 109.
- `extension/chrome-modern/` — современный Chrome/Chromium.
- `extension/firefox115-esr/` — Firefox 115 ESR.
- `extension/firefox-modern/` — современный Firefox.

Варианты содержат отдельные манифесты/фоновую конфигурацию для различий браузеров.

## Android

Каталог `android/` содержит Gradle-проект. Приложение запускает выбранный материал во внешнем браузере; для сборки APK нужны Android SDK и Gradle.
