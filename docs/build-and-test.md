# Сборка и проверка

## Браузерные расширения

1. Распакуйте нужный каталог из `extension/`.
2. Откройте страницу управления расширениями браузера.
3. Включите режим разработчика (если требуется) и выберите загрузку распакованного расширения.
4. Укажите соответствующий каталог.
5. Откройте `https://rezkery.com/` и проверьте выбор случайной карточки, фильтры, локальную базу, импорт/экспорт и пользовательский домен.

### Проверка синтаксиса

Для JavaScript-файлов можно выполнить `node --check path/to/file.js`. JSON манифесты должны успешно разбираться стандартным JSON-парсером.

## Android

Требуются JDK 17, Android SDK и Gradle. Из каталога `android/` выполните:

```sh
gradle assembleDebug
```

APK обычно создаётся в `android/app/build/outputs/apk/debug/`.

## GitHub Actions

- `validate.yml` проверяет манифесты и синтаксис JavaScript, затем сохраняет архивы расширений как артефакт.
- `android.yml` пытается собрать Android debug APK и сохраняет его как артефакт.

Проверки GitHub Actions нужно подтвердить после первого запуска в репозитории; локальная статическая проверка сама по себе не гарантирует успешную сборку APK.
