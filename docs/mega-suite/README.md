# Rezka: разбор архивов и план объединения

Статус: исследование и проектирование по выбору пользователя; реализация функций ещё не начата.

Изучены восемь предоставленных ZIP-архивов и текущая версия `divanvkarman77/rezkery-randomizer` на коммите `a0c6854b0ab7263dee44c2fed017191eca44b775`. Проверены исходники, manifest, форматы данных, фоновые операции и экспорт. Проверка синтаксиса прошла для всех 40 JavaScript-файлов архивов. Проверены существование фоновых скриптов, popup и иконок, указанных в manifest. Полноценный запуск расширений и обращения к аккаунту HDRezka в рамках разбора не выполнялись.

## Вывод

Материала достаточно для общего приложения с рандомом, библиотекой, каталогами, закладками и автономным HTML. Основа — текущий рандомайзер, дополненный проверенными механизмами из разных архивов. Единый формат данных и отдельные адаптеры для Android, Chrome и Firefox позволят переносить коллекцию между всеми приложениями.

Приоритетное изменение: отделить **известные фильмы библиотеки** от **истории уже выбранных карточек**. Иначе импорт полного каталога превратит всю библиотеку в список исключений рандома. Папку RANDOM можно импортировать в историю без повторов отдельно; обычные каталоги должны пополнять библиотеку.

## Как будет выглядеть общий интерфейс

1. **Рандом** — общий каталог, год/диапазон, типы контента, количество карточек, подбор из локальной библиотеки, история без повторов.
2. **Библиотека** — карточки и список, поиск, фильтры, сортировка, просмотренное, личные оценки, заметки, коллекции и метки.
3. **Каталоги** — сохранённые разделы сайта, годы, страницы персон, ручные подборки и запуск ограниченного сбора.
4. **Закладки** — папки аккаунта, RANDOM, Desktop FAV, импорт и выгрузка с отображением результата по папкам.
5. **Файлы и синхронизация** — резервные копии, импорт старых форматов, HTML, Gist и обмен между устройствами.

Шестерёнка содержит зеркала, задержки, таймауты, автоматизацию, лимиты кэша и настройки экспорта. Переключатель темы остаётся доступным в шапке. Простому режиму доступны основные действия; дополнительные поля раскрываются по месту.

На Android используются те же разделы и модель данных. Полноэкранные разделы предпочтительнее цепочки вложенных диалогов. Возврат из фильма восстанавливает раздел, фильтры и прокрутку. Автономный HTML — отдельный переносимый просмотрщик коллекции с поиском, фильтрами, темой и локальным рандомом.

## Рекомендуемый порядок

| Этап | Результат |
| --- | --- |
| 1. Общая база и миграции | Единый ID, раздельная история, импорт всех старых форматов без потери папок и личных данных |
| 2. Очередь и пагинация | Восстановление операций, общий темп запросов, остановка на проверке защиты, проверка реально загруженной страницы |
| 3. Закладки | Все папки, RANDOM и Desktop FAV; повторная синхронизация не создаёт дубли |
| 4. Менеджер библиотеки | Карточки, оценки, заметки, коллекции, поиск и фильтры во всех приложениях |
| 5. Постеры и HTML | Общий кэш, описания, оригиналы постеров и обновляемые автономные каталоги |
| 6. Обмен и выпуск | Полная копия с медиа, лёгкая синхронизация метаданных, проверка четырёх расширений и Android |

Первый полезный выпуск после этапов 1–3: рандомайзер с общей переносимой базой, совместимым импортом и надёжными закладками. Полный набор функций появляется после этапов 4–6. Сроки не оценивались до проверки миграций и объёмов реальных пользовательских баз.
